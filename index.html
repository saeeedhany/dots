2 design

the screen should get out of the way. every rule below removes something.

  1. one colorthe wallpaper, the bar, the terminal and the menus share one background, so the screen reads as a single surface.
  2. text over iconsthe bar says cpu 48°C. there is nothing to decode and nothing to install a font for.
  3. only what gets usedno window titles, no docks, no tray. the bar keeps the tags, the layout and the status, nothing else.
  4. keyboard firstevery action has a key. the mouse is optional.
  5. built from sourcedwm, st and dmenu are compiled with their patches. changing them means changing a header and running make.
  6. linked, not copiedediting ~/.config/nvim or ~/.bashrc edits the repo. the machine and the repo cannot drift apart.
  7. one place per machineanything only one computer needs goes in ~/.config/local.sh for the session or ~/.config/local.bash for the shell. neither is ever committed.

the whole system, every color, rule and the code behind it, is on the design page. why each program is set up the way it is lives in the blog.

~ ❯ theme

3 themes

one command repaints the whole machine.

wallpaper, dwm, st, dmenu, tmux, the prompt, fzf, dunst, zathura, neovim, opencode, btop, rmpc, gtk and qt apps, gimp, kdenlive, obs, vesktop, firefox and zen all change together. nnn, ranger and cava follow the terminal on their own. pick one to repaint this page the same way.

❯ theme list themes, * marks the current one ❯ theme black switch the whole machine ❯ theme new 2b2f2a build a whole theme from one color ❯ theme new 2b2f2a moss same, with your own name

to make one by hand, copy a file in themes/ and change its colors. theme refuses a theme with a missing or malformed color and names it, and the tests refuse one whose text is hard to read.

4 install

on a fresh arch machine, as your normal user:

git clone https://github.com/saeeedhany/dots ./dots/install.sh
okcheckarch, sudo and a network
okpackagesonly what the configs actually call
okauryay, then the few aur packages
oksucklessdwm, st, dmenu and dwmblocks, built and installed
oklinksevery config linked into place
okfoldersone word home folders: downloads, documents, pictures
okdefaultsimages open in imv, pdfs in zathura
okwallpaperscopied to ~/pictures/wallpapers
okfontsrefreshed
okthemegrey, unless you pick another
okverifychecks everything landed and names anything missing

options

❯ ./install.sh --dry-run show every step, change nothing ❯ ./install.sh --only links,theme run just these steps ❯ ./install.sh --skip packages run everything else ❯ ./install.sh --theme black start in another theme ❯ ./install.sh --all every package from the origin machine

good to know

anything already on the machine is kept as name.bak.time before it is replaced, and running the installer again is safe.

log in on tty1 and x starts by itself, straight into dwm.
